# 🚀 Getting Started

## 📦 Install Dependencies

```bash
npm install
```

---

## 💻 Run Frontend

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

---

## ⚡ Run Backend

```bash
cd server
npm run dev
```
